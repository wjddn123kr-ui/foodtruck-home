# 푸드트럭하우스 접근성 규칙 (WCAG AA)

품질 바닥이다. 아래 3개는 모든 페이지에서 지킨다.

## 1. 이미지 alt — 전부

- 모든 `<img>`에 `alt` 속성. 내용을 전달하는 이미지는 **무엇인지 설명**(파일명·"이미지" 같은 무의미한 값 금지).
- **장식용** 이미지(순수 배경·구분선)는 `alt=""`(빈 값)으로 스크린리더가 건너뛰게 한다.
- 배경이 CSS `background-image`면 의미 있는 내용은 인접 텍스트로 제공.
- 아이콘 버튼은 보이는 글자가 없으면 `aria-label`로 이름을 준다.

## 2. 키보드 접근 — 버튼·링크

- 클릭 가능한 건 **네이티브 `<button>`/`<a>`**로. `<div onclick>` 지양(포커스·엔터 동작이 공짜로 안 옴).
- 모든 인터랙티브 요소는 **Tab으로 도달, Enter/Space로 실행** 가능해야 한다.
- **`:focus-visible` 포커스 링**을 눈에 띄게 유지한다. `outline:none`으로 지우기만 하고 대체 안 하는 것 금지.
- 포커스 순서는 시각 순서와 일치. 모바일 드로어 열릴 때 포커스 관리(가능하면 트랩·`Esc` 닫기).
- 링크 텍스트는 목적을 알 수 있게("여기 클릭" 금지).

## 3. 색 대비 — WCAG AA

- **본문 텍스트 4.5:1 이상**, 큰 텍스트(약 24px+ 또는 굵은 19px+) **3:1 이상**.
- UI 컴포넌트(버튼 테두리·아이콘·입력창 경계)와 상태 표시도 **3:1 이상**.
- 일렉트릭 블루(#2D5BFF) 위 흰 글자, 딥네이비 위 `--mute(#93A1C7)` 보조텍스트 등은 대비를 실제로 확인한다. 딥네이비 배경에 어두운 파랑 텍스트 같은 저대비 조합 금지.
- 정보를 **색으로만** 전달하지 않는다(상태는 아이콘·텍스트 병행).

## 4. 기타

- `<html lang="ko">`, 의미 있는 제목 계층(h1→h2→h3, 건너뛰기 금지).
- 폼 입력은 `<label>` 연결. 에러는 색+텍스트로(→ form-validation 스킬과 함께).
- `prefers-reduced-motion` 존중.

## 셀프 체크

1. 모든 img에 alt 있는가?(장식은 `alt=""`, 아이콘버튼은 aria-label)
2. 클릭 요소가 button/a인가? Tab·Enter로 조작되고 focus-visible 링 보이는가?
3. 본문 4.5:1 / 큰 글자·UI 3:1 대비를 만족하는가?
4. 정보를 색으로만 전달하지 않는가?
5. 제목 계층·lang·label이 올바른가?
