# 푸드트럭하우스 견적폼 규칙

3분(3초) 견적폼/챗봇의 입력 검증·표기 규칙이다. 견적 버튼은 최종적으로 작업자 Claude 챗봇에 연결 예정([[quote-chatbot-plan]]), 현재는 카톡 임시연결.

## 1. 최소 음식값 60만원

- 견적의 **음식 금액 최소 60만원**. 미만이면 진행을 막고 안내한다.
- 에러 예: **"현장 운영 특성상 최소 견적 금액은 60만원부터예요. 인원·메뉴를 조금 늘리면 딱 맞출 수 있어요 🙂"**
- 계산 로직은 최소값을 하한으로 clamp하지 말고, **명확히 알리고** 사용자가 조정하게 한다.

## 2. 연락처 필수 — 게이트

- **연락처(전화번호)는 필수 게이트.** 연락처 없이는 최종 견적 결과/제출로 넘어가지 못한다.
- 전화번호 형식 검증(휴대폰/유선). 하이픈 유무 모두 허용하되 숫자·자릿수 확인.
- 게이트에서 막을 때도 강압적이지 않게: **"견적 결과를 문자로 보내드릴게요. 연락처만 남겨주시면 바로 확인하실 수 있어요."**
- 개인정보: 최소 수집. 마케팅 활용 동의는 분리(강제 아님).

## 3. VAT 별도 표기

- 모든 금액은 **부가세(VAT) 별도**임을 명확히 표기한다. 금액 옆·합계 근처에 **"(VAT 별도)"**.
- 원하면 "공급가 / VAT / 합계(VAT 포함)"를 나눠 보여줘도 되지만, **별도라는 사실은 반드시** 눈에 띄게.
- 최소 60만원 안내도 "음식값(VAT 별도) 기준"임을 함께 표기.

## 4. 친절한 에러 문구

- 잘못된 입력엔 **무엇이·왜·어떻게 고치는지**를 사람 말투로. 시스템 용어·"invalid"·빨간 경고만 던지기 금지.
- 톤: 브랜드 무드(젊음·신뢰)에 맞게 부드럽게, 사과하지 말고 방향을 준다. 필요 시 이모지 하나 정도 허용.
- 에러는 **색 + 텍스트**로(색만 금지 → accessibility 규칙), 해당 입력창 근처에 표시하고 포커스 이동.
- 예시:
  - 빈 필수값: "행사 날짜를 선택해 주세요."
  - 전화 형식: "연락처를 다시 확인해 주세요. 예) 010-1234-5678"
  - 인원 0/음수: "예상 인원을 1명 이상으로 입력해 주세요."

## 셀프 체크

1. 음식값 60만원 미만을 막고 친절히 안내하는가?
2. 연락처 없이는 결과로 못 넘어가는 게이트가 있는가? 형식 검증하는가?
3. 금액에 "(VAT 별도)" 표기가 있는가?
4. 에러 문구가 사람 말투 + 해결 방법 안내인가? 색만으로 표시하지 않는가?
