# 푸드트럭하우스 모바일 퍼스트 규칙

기본 CSS는 **모바일**이고, 데스크톱은 예외로 덮어쓴다. 대부분 방문자가 모바일이므로 모바일에서 먼저 확인한다. 아래 5개는 협상 불가.

## 1. 768px 단일 분기점만

- **기본 CSS = 모바일.** 데스크톱은 `@media (min-width: 768px)`에서만 덮어쓴다.
- 브레이크포인트는 **768px 하나로 통일.** 여러 분기점(480/640/1024…)을 흩뿌리지 않는다.
- `min-width` 방식으로 위로 확장(모바일 퍼스트). `max-width` 하향식과 섞지 않는다.
- 정말 불가피한 예외가 생기면 그 이유를 주석으로 남긴다.

## 2. 터치 타겟 최소 44×44px

- 버튼·링크·아이콘·탭 등 **누르는 요소는 최소 44×44px**(권장 48px). 시각 아이콘이 작아도 패딩/`min-height`/`min-width`로 히트 영역을 확보한다.
- 인접 터치 타겟 사이 간격을 충분히(오탭 방지, 약 8px+).
- 아이콘만 있는 버튼은 히트 영역을 넓히고 `aria-label` 부여(→ accessibility 규칙).

## 3. 가로 스크롤 절대 금지

- 어떤 뷰포트에서도 **가로 스크롤이 생기면 안 된다.**
- 흔한 원인과 대응:
  - 고정 `width`(px) 요소 → `max-width:100%` / `width:100%`로.
  - 넘치는 이미지·비디오·표 → 4번 규칙, 표는 컨테이너 `overflow-x:auto`로 격리.
  - 큰 음수 마진·`100vw`(스크롤바 폭 무시) → 지양.
  - 긴 단어/URL → 필요 시 `overflow-wrap:anywhere`.
- 안전장치로 필요 시 `html,body{overflow-x:hidden}`을 쓰되, **원인을 먼저 제거**한다(숨김은 최후 수단).

## 4. 이미지는 화면 폭 초과 금지

- 모든 이미지·비디오·iframe은 **`max-width:100%; height:auto;`** 기본.
- 반응형 이미지는 `<picture>`/`srcset`으로 모바일엔 작은 파일(→ performance 규칙). 데스크톱 대용량을 모바일에 내리지 않는다.
- 레이아웃 이동 방지를 위해 `width`/`height` 속성 또는 `aspect-ratio` 지정.

## 5. 본문 글자 최소 16px

- **본문 텍스트는 최소 16px**(1rem). 캡션·라벨도 너무 작게(≤12px) 만들지 않는다.
- 입력창(`input`/`select`/`textarea`)도 16px 이상 → iOS에서 포커스 시 자동 확대 방지.
- 줄 간격·대비도 함께 확보(→ accessibility의 대비 4.5:1).

## 셀프 체크 (모바일에서 실제로 확인)

2. 모든 터치 요소가 44×44px 이상인가?
3. 가로 스크롤이 없는가?(원인 제거 확인)
4. 이미지가 화면 폭을 넘지 않는가?(`max-width:100%`)
5. 본문·입력이 16px 이상인가?
