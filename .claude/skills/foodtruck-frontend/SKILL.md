# 푸드트럭하우스 프론트엔드 구현 규칙

푸드트럭하우스 UI를 만들 때 지키는 **구체 구현 규칙**(색/폰트/반응형/CSS 스코프)이다.
"왜 이 무드인가"(브랜드·모션·콘텐츠)는 **[[foodtruck-brand]]** 스킬에, 일반 디자인 감각은 **내장 frontend-design** 스킬에 있다. 이 스킬은 그 위에서 **손이 지켜야 할 규칙**만 짧게 못박는다.

## 0. 진실의 원천

토큰의 정본은 이 문서가 아니라 **현재 `index.html`의 `:root` 변수 + `assets/css/style.css`**다.
작업 시작 시 항상 그 값을 먼저 읽고 그대로 쓴다. 새 색을 하드코딩하지 말고 기존 변수를 참조하거나 `:root`에 추가한 뒤 참조한다. 아래 값은 정본이 비었을 때의 폴백이다 — **실제 파일 값이 이긴다.**

## 1. 색상 — 딥네이비 + 일렉트릭블루

- **베이스:** 딥네이비 배경. `--navy-900:#060C1F` / `--navy-850:#0A1430` / `--navy-800:#0E1A3D`(카드).
- **포인트(단 하나):** 일렉트릭 블루 `--blue:#2D5BFF`. 글로우 CTA·라이브 점등·강조선에만 쓴다. 남발 금지 — 포인트는 화면당 소수.
- **보조:** `--blue-deep:#003892`(브랜드 블루) / `--blue-bright:#5B86FF`.
- **텍스트:** 다크 위 본문 `--ice:#EAF0FF`, 보조 `--mute:#93A1C7`. 라이트 섹션은 배경 `--paper:#F4F7FE` / 텍스트 `--ink:#0A1124`.
- **선:** `--line:rgba(140,165,225,.16)`.
- 형광·다색 키치 컬러 금지. 포인트 컬러는 **파란색 계열 하나**로만.

## 2. 타이포

- **헤드라인:** `Black Han Sans`(굵은 임팩트 국문 헤드라인). 큰 제목·숫자 강조에.
- **본문:** `Pretendard`(CDN). 기본 본문·라벨·버튼.
- 폰트는 `assets/css/style.css`에서 `@import`로 로드하고, `font-family` 변수(예: `--ff-head`, `--ff-body`)로 참조. 페이지마다 재선언하지 않는다.
- 타입 스케일·굵기·자간을 의도적으로 잡는다. 헤드라인은 Black Han Sans의 무게를 살려 크게, 본문은 Pretendard로 차분하게.

## 3. 반응형 — 모바일 퍼스트, 768px 단일 분기점

- **기본 CSS = 모바일.** 데스크톱은 `@media (min-width: 768px)`에서만 덮어쓴다.
- 분기점은 **768px 하나로 통일.** 여러 브레이크포인트를 흩뿌리지 않는다(정말 필요할 때만 예외, 그때도 이유를 남긴다).
- 모바일에서 먼저 확인: 가로 오버플로우 없음, 터치 타깃 충분, 히어로 텍스트 가독성.
- 품질 바닥: `focus-visible` 포커스 링, `prefers-reduced-motion` 존중(모션·배경영상 숨김).

## 4. CSS 스코프 클래스

전역 오염을 막기 위해 **스코프 접두사**를 붙인다:

- `.ftp-` — 푸드트럭하우스 **공통/페이지 컴포넌트** 접두사(FoodTruckHouse Page). 일반 UI 요소에 사용.
- `.fts3-` — **특정 섹션(Section 3) 전용** 스코프. 그 섹션 안에서만 사는 스타일에 사용해 다른 섹션과 충돌을 막는다.
- 규칙:
  - 새 컴포넌트 클래스는 반드시 접두사로 시작. 접두사 없는 전역 `.card`, `.btn`, `.title` 같은 이름 금지.
  - 섹션 국지 스타일은 `.fts3-` 같은 섹션 스코프 안에 둔다.
  - **셀렉터 특이도 충돌 주의:** 타입 기반(`.section`)과 요소 기반(`.cta`) 셀렉터가 서로 padding/margin을 상쇄하기 쉽다. 섹션 간 간격은 스코프 클래스 안에서 한 방향으로만 지정한다.

## 5. 셀프 체크(코드 쓰기 전/후)

1. 색: 딥네이비 배경 + 일렉트릭블루 포인트 하나만 썼는가? 하드코딩 색 대신 변수?
2. 폰트: 헤드라인 Black Han Sans / 본문 Pretendard, 변수 참조?
3. 반응형: 모바일이 기본, 768px에서만 데스크톱 덮어쓰기?
4. 스코프: 모든 새 클래스가 `.ftp-`/`.fts3-`로 시작? 전역 이름 없음?
5. 품질: focus-visible, reduced-motion, 모바일 오버플로우 확인?
